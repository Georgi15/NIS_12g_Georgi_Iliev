Описание на фирмата
Предоставя физическа и дигитална охрана за корпоративни клиенти. Централата е в София,
регионалните командни центрове са в Пловдив и Варна. Видеонаблюдението се стриймва
само към централата. Операторите нямат право да записват локално. Само централата може
да инициира двупосочна комуникация с командните центрове.
